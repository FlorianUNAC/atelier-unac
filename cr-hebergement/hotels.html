Liste des hôtels (chiffrée)

1 · Charger la liste

Importez le fichier des hôtels (Excel ou CSV). Colonnes reconnues automatiquement : trigramme (ou ville), hôtel, étoiles, fin / échéance du contrat, et éventuellement LC / MC. Le fichier est lu uniquement sur cet appareil.

2 · Vérifier

RéseauCodeVilleHôtelÉtoilesFin de contrat

3 · Chiffrer et mettre en ligne

Choisissez une phrase secrète longue (au moins 4 mots, par exemple « valise rouge escale minuit »), différente du code d'accès à l'Atelier. Transmettez-la uniquement aux délégués, de vive voix ou par message privé. Elle n'est jamais enregistrée sur le site : sans elle, le fichier en ligne est illisible. Si vous la changez, chaque délégué devra saisir la nouvelle.

La publication utilise le jeton GitHub enregistré sur cet appareil (menu Historique → « Publication pour tous les délégués »). Sans jeton : téléchargez le fichier chiffré et déposez-le sous le nom cr-hebergement/hotels.enc.json dans le dépôt.
