Formulaires

Les formulaires PDF à remplir par les délégués, à télécharger directement. Remplis et enregistrés, ils s'importent tels quels dans les outils de l'Atelier.

Les formulaires se remplissent dans Acrobat Reader, Aperçu (Mac) ou un navigateur. Renvoyez le fichier enregistré, pas une version imprimée en PDF : les champs seraient perdus.
